# Workflow: retention audit

1. **Reconstruct the loop** from the game (playtest or code/config): action → reward → progression →
   reinvestment, at session/daily/weekly/long-term scales (retention-design.md §2).
2. **First-session walkthrough with timestamps** (§4 table): first control, first reward, first upgrade, first
   new mechanic, first "wow", first reason to return. Mark anything later than target.
3. **Stall points:** economy_sim walls, confusing UI, dead ends, empty servers.
4. **Hook inventory** per time scale; missing scales are the opportunities (daily is usually the gap).
5. **Data:** funnels (AnalyticsService), D1/D7/D30 and session length from the Creator Dashboard; plan one
   Experiment for the biggest stall.
6. **Ethics/policy pass:** red lines in retention-design.md §6.
7. **Output:** stall list, missing hooks, 3–5 prioritized changes with expected metric impact.
