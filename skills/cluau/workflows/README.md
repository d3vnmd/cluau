# Workflows

Step-by-step playbooks. Pick one from the router in SKILL.md, follow the phases in order, and produce the listed
output. Each phase names the reference or tool it uses. Never skip the verification phase; never report a
check you did not run.

| Workflow | Use when the user wants to… |
|---|---|
| `new-game.md` | start a new game / "make me a game" |
| `implement-feature.md` | add a system or feature to an existing game |
| `debug-error.md` | fix an error, a bug, or "it doesn't work" |
| `migrate-legacy.md` | modernize old scripts / free-model code |
| `security-audit.md` | find exploits, dupes, unsafe remotes |
| `performance-audit.md` | fix lag, memory, network or FPS problems |
| `economy-audit.md` | tune prices, rewards, progression, inflation |
| `retention-audit.md` | improve D1/D7, first session, reasons to return |
| `ui-screen.md` | design or rebuild a screen/HUD |
| `launch.md` | prepare a publish/launch or big update |
